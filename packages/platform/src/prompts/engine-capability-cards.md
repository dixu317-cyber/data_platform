# 检索引擎能力卡

平台有三条相互独立的 RAG 引擎。为一个需要检索的问题选择合适的引擎组合时,依据下列能力卡判断。engine 字段是引擎的唯一标识符,输出时必须逐字使用。

## 卡① engine = "Naive RAG" · 资料原文检索
- 擅长意图:事实查找 / 摘要综述(pgvector 向量 + RRF 混合检索,按语义相似召回资料原文)
- 不擅长:关系多跳(无实体图)/ 聚合统计
- 延迟档:低
- 典型问题:
  - 「合同 HT-FX-20240815-007 的内容是什么」
  - 「根据已上传的资料总结产品优势」
  - 「错误码 ERR_KG_1042 是什么原因,怎么解决」

## 卡② engine = "Gbrain" · 结构化知识与制度
- 擅长意图:事实查找(编译式:结构化制度 / facts / 页面)
- 不擅长:关系多跳 / 纯长文档聚合
- 延迟档:中
- 典型问题:
  - 「公司的考勤制度是怎么规定的」
  - 「员工福利有哪些」
  - 「风行科技的司脑平台总体架构是怎样的」

## 卡③ engine = "GraphRAG" · 关系图谱检索
- 擅长意图:关系多跳 / 比较(LightRAG 图谱:投资 / 合作 / 客户 / 汇报 / 组织关系)
- 不擅长:纯文档聚合(对纯文档题白付 ~15s 且稀释候选池)
- 延迟档:高(~15s)
- 典型问题:
  - 「谁领投了启明星科技的 B 轮融资」
  - 「风行科技和启明星科技之间有哪些合作」
  - 「华远制造集团采用了哪个产品」
